และจะไม่มีวันมีตารางราคาด้วย: นี่ไม่ใช่สินค้าเชิงพาณิชย์ แต่เป็นสมบัติส่วนรวมทางดิจิทัล แบบโอเพนซอร์ส — มีประโยชน์กับทุกคน สร้างโดยทุกคน โค้ดของเราเปิดเผย (ภายใต้สัญญาอนุญาต Captain.Food Coopyleft — copyleft ที่ต่อยอดจาก AGPL สงวนการใช้งานเชิงพาณิชย์ไว้ให้เฉพาะองค์กรในเศรษฐกิจเพื่อสังคมและความเป็นน้ำหนึ่งใจเดียวกัน)

ร้านอาหาร & ฟู้ดทรัคอิสระ

0 €สำหรับคุณ วันนี้ — และเราจะสู้เพื่อให้มันเป็นแบบนี้ตลอดไป

  • ค่าคอมมิชชั่น 0 % จากอาหารของคุณ — ไม่มีวันหักเปอร์เซ็นต์จากกำไรของคุณ
  • ค่าสมาชิก 0 € ไม่มีแพ็กเกจรายเดือน ไม่มีขั้นบันไดราคาให้จ่ายเพิ่ม
  • ค่าสมัคร 0 € และไม่มีค่าติดตั้งใด ๆ
  • ข้อผูกมัด 0 — คุณใช้ Uber Eats & Deliveroo ควบคู่กันต่อได้
  • ลูกค้ายังเป็นของคุณ ตั้งแต่ออร์เดอร์ตรงแรก

⚓ ยังไม่มีอะไรถูกสร้างขึ้น Captain.Food เพิ่งเริ่มต้นที่เมือง Tours กับเจ้าของร้านกลุ่มแรก แต่โมเดลชัดเจนตั้งแต่วันแรก: ฟรีสำหรับคุณ ของจริง

« ฟรี… แล้วกับดักอยู่ตรงไหน? »

ไม่มีเลย แพลตฟอร์มอยู่ได้ด้วยเงินสมทบตามใจสมัครของผู้ใช้: ตอนสั่งอาหาร ลูกค้าเลือกเพิ่มเงินสมทบตามใจสมัครลงในตะกร้าได้ถ้าต้องการ — ให้ 0 € ก็ได้ ไม่มีการตัดสิน นี่คือการเดิมพัน: ว่าลูกค้าที่รู้ข้อมูลจะเลือกสนับสนุนร้านค้าท้องถิ่นของตัวเองมากกว่าบริษัทข้ามชาติ

ส่วนคุณ ไม่ต้องจ่ายอะไรเลย: ไม่มีวันหักเปอร์เซ็นต์จากกำไรของคุณ ไม่มีวันมีค่าบวกเพิ่มที่ใครแอบเพิ่มแทนคุณ โครงการนี้ดำเนินการโดยสมาคมไม่แสวงหากำไร ออกแบบมาให้ไม่มีวันกลายร่างเป็นด่านเก็บค่าผ่านทางได้ เราหาทุนอย่างไร อ่านแบบชัด ๆ →

การเดิมพันของเรา อย่างโปร่งใสที่สุด

ฟรี ตั้งอยู่บนการเดิมพัน: ว่าเงินสมทบตามใจสมัครจะเพียงพอหล่อเลี้ยงสมบัติส่วนรวมนี้ เราเชื่ออย่างนั้น — และเราบอกคุณตรง ๆ ว่าถ้าไม่เป็นอย่างนั้น จะเกิดอะไรขึ้น

มันจะไม่มีวันเป็นตารางราคา และไม่มีวันเป็นการบวกกำไร อย่างแย่ที่สุด เราจะแบ่งกันจ่ายตามต้นทุนจริง เท่าที่จำเป็นเพื่อให้ระบบเดินต่อได้:

  • ฝั่งลูกค้า — ค่าร่วมสมทบค่าดำเนินการเล็กน้อยต่อออร์เดอร์ ส่วนที่จ่ายเกินจากนั้นยังคงเป็นเงินสมทบ
  • ฝั่งเจ้าของร้าน — ส่วนแบ่งของต้นทุนจริง หารตามจำนวนเจ้าของร้านที่ขึ้นเรือมา: ยิ่งเราเยอะ ยิ่งจ่ายน้อย ไม่มีวันเป็นค่าคอมมิชชั่น ไม่มีวันเป็นเปอร์เซ็นต์จากอาหารของคุณ

และทันทีที่โมเดลเอื้อ ทั้งหมดนี้จะหายไป: กลับสู่ฟรี เป้าหมายไม่ใช่การขายสินค้า แต่คือการรักษาสมบัติส่วนรวมที่เปิดให้ทุกคน

คำถามที่มีคนถามเราบ่อย ๆ

ฟรี 100 % สำหรับร้านของฉันจริง ๆ เหรอ?

จริง ค่าคอมมิชชั่น 0 % จากอาหารของคุณ ค่าสมาชิก 0 € ไม่มีค่าสมัครหรือค่าติดตั้ง และไม่มีข้อผูกมัด ค่าบริการเท่ากันสำหรับทุกคน: ฟรี

มีค่าสมาชิกหรือแพ็กเกจแอบแฝงไหม?

ไม่มี ไม่มีค่าสมาชิก ไม่มีแพ็กเกจ ไม่มีขั้น « พรีเมียม » ให้จ่ายเพิ่ม ส่วนเงินที่จ่ายเข้าเครื่องเก็บเงินตามปกติของคุณ (ที่ร้าน หน้าเคาน์เตอร์) เราก็ไม่ยุ่งเช่นกัน

แล้วพวกคุณอยู่ได้ด้วยอะไร?

ด้วยเงินสมทบตามใจสมัครของลูกค้า (ให้ 0 € ก็ได้) นี่คือการเดิมพัน: ถ้ามันไม่พอ ก็จะไม่มีวันมีค่าคอมมิชชั่นหรือตารางราคา — อย่างแย่ที่สุดคือแบ่งกันจ่ายตามต้นทุนจริง (ค่าร่วมสมทบเล็กน้อยฝั่งลูกค้า ส่วนแบ่งต้นทุนจริงฝั่งเจ้าของร้าน) และถูกออกแบบให้หายไปทันทีที่โมเดลเอื้อ ไม่มีวันอยู่บนหลังของคุณ ดูรายละเอียดทั้งหมด
