„Gratis … und wo ist der Haken?“

Es gibt keinen. Die Plattform lebt vom freiwilligen Beitrag ihrer Nutzer: Beim Bestellen kann der Gast, wenn er möchte, einen frei wählbaren Beitrag in seinen Warenkorb legen — 0 € möglich, ohne Wertung. Eine Wette: darauf, dass informierte Gäste lieber ihr lokales Geschäft unterstützen als einen Weltkonzern.

Du zahlst nichts: nie einen Prozentsatz auf deine Marge, nie einen Aufschlag, den wir an deiner Stelle draufpacken. Das Projekt wird von einem Verein ohne Gewinnzweck getragen — so gebaut, dass es nie zur Mautstelle werden kann. Wie wir uns finanzieren, ganz offen →

Unsere Wette, in voller Transparenz

Gratis beruht auf einer Wette: dass der freiwillige Beitrag reicht, um dieses Gemeingut am Laufen zu halten. Wir glauben daran — und sagen dir ohne Umschweife, was sonst passieren würde.

Es wird nie eine Preistabelle und nie eine Marge sein. Schlimmstenfalls würden wir zum Selbstkostenpreis das Nötigste teilen, um den Betrieb zu decken:

  • Auf Gastseite — eine kleine Beteiligung an den Betriebskosten pro Bestellung. Alles, was darüber hinaus gegeben wird, bleibt ein Beitrag.
  • Auf Gastronomenseite — ein Anteil an den realen Kosten, verteilt auf die Zahl der Gastronomen an Bord: je mehr wir sind, desto kleiner wird er. Nie eine Provision, nie ein Prozentsatz auf deine Gerichte.

Und sobald das Modell es erlaubt, verschwindet das alles wieder: zurück zum Gratis-Modell. Das Ziel ist nicht, ein Produkt zu verkaufen, sondern ein Gemeingut offen für alle zu halten.

Die Fragen, die man uns stellt

Ist das wirklich 100 % gratis für mein Restaurant?

Ja. 0 % Provision auf deine Gerichte, 0 € Abo, 0 Anmelde- oder Einrichtungsgebühren, unverbindlich. Der Preis ist für alle derselbe: gratis.

Gibt es ein Abo oder ein verstecktes Paket?

Nein. Kein Abo, kein Paket, keine „Premium“-Bezahlstufe. Was in deiner gewohnten Kasse bezahlt wird (vor Ort, am Tresen), rühren wir ebenfalls nicht an.

Und wovon lebt ihr dann?

Vom freiwilligen Beitrag der Gäste (0 € möglich). Eine Wette: Reicht er nicht, gibt es trotzdem nie eine Provision und nie eine Preistabelle — schlimmstenfalls ein Teilen zum Selbstkostenpreis (kleine Kostenbeteiligung auf Gastseite, Anteil an den realen Kosten auf Gastronomenseite), das verschwindet, sobald das Modell es erlaubt.
