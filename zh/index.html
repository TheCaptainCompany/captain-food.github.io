🛟 航向锁定，绝不漂移

一个永远无法变成收费站的替代方案

Captain.Food 源于一个朴素的信念：数字技术应当是公共利益的工具，而不是握在几家科技巨头手里的收费站。问题不在于它们赚钱——而在于一旦你离不开它们，它们就可以拧紧螺丝，没有任何东西能拦住。

所以我们给自己上了靠得住的保险。我们的目标是取得法国社会公益互助企业（ESUS）认证——一个从法律上限制逐利、锁定使命的框架——并朝合作社（SCIC，法国公益合作社地位）的方向前进，让餐饮人、骑手和市民都有发言权。目标只有一个：从制度设计上，就不可能变成我们所反对的东西。

而且你不必只听我们说：我们的账目在 Open Collective 上公开——收进的每一欧元、花出的每一欧元，都将对所有人可见。要的是彻底透明，不是口号。

我们的愿景：让 Captain.Food 成为一件数字公共财产，而不是私人资产。代码全部开源——就在 GitHub 上——采用 Captain.Food Coopyleft 许可证（基于 AGPL v3 的 copyleft，秉承 CoopCycle 的精神），商业使用仅限社会互助经济组织——合作社与非营利机构。我们的航向：让它获得数字公共产品 (digital public good) 认定——可验证，更重要的是可复制：其他城市、其他合作社都能拿去接着用。公共利益的工具，只能分享——不能转卖。阅读宣言 →

大家常问我们的问题

餐饮人问过我们的一切——直截了当，明明白白。

对我免费——那你们靠什么活？

对你来说：菜品0%佣金、注册免费，任何情况下都是。服务靠客人下单时透明添加的随心支持金来维持（给0 €也可以，绝不评判）——永远不由你出。银行卡手续费就是任何线上收款都有的标准银行费用，绝不会额外转嫁给客人。看完整说明，附实例。

那客人在收银台付的钱呢？

凡是走你自家收银台的（堂食、柜台），我们一概不碰：免费，就这么简单，完全在我们的资金流之外。支持金只涉及通过 Captain.Food 在线支付的订单。

那配送费，谁来出？

配送将是一个即将上线的渠道，目前还没启用。思路是：让骑手拿到公道报酬（目标每单至少7 €）。你只在自己的外送订单上出一部分，出多少以你的利润承受度为限——底线由你来定，我们绝不越过。差额由客人透明补足。永远不会是菜品佣金。看详细算法，附实例。

我得退出 Uber Eats / Deliveroo 吗？

不用。Captain.Food 是加法，没有排他。很多餐厅两边都留着，把 Captain.Food 当作自己的直连渠道——真正握在自己手里的那一个。

平台上还没有客人，我现在注册图什么？

因为它不花你一分钱，也不要求任何排他。你先占好位置，从第一笔直接订单起就开始积累自己的客户名单，还能在起步阶段亲手塑造这个工具。最早登船的人，话语权最大。

我怎么拿回我的客人？

每一笔在你页面上直接下的订单都归你：你可以拿到客人的联系方式（经其同意），自己去维护熟客。和大平台不一样，我们不没收你的客源。

ESUS 企业是什么？

「社会公益互助企业」：一种法国官方认证，从法律上限制逐利、要求企业承担社会使命。这是我们瞄准的航向——最终确保 Captain.Food 永远不会滑向我们所抨击的模样。

那桌边扫码点餐（QR code）呢？

分两种情况。客人在收银台或当面付款，就完全在我们的资金流之外：100%免费，我们不碰。客人扫码后在线付款，则和普通在线订单一样，可以自愿添加支持金。无论哪种，都挂你的名字，菜品0佣金。
